## Обзор

Проект демонстрирует ключевые концепции блокчейна:

- **Связный список блоков** через хеш предыдущего блока.
- **Proof-of-Work** — майнинг с настраиваемой сложностью.
- **UTXO-модель** транзакций (Unspent Transaction Outputs).
- **Криптографические подписи** Ed25519 для подтверждения владения монетами.
- **Персистентное хранение** блоков и UTXO-сета в `sled`.

Цель — не production-ready система, а понятная учебная база, где каждый компонент можно изучить и расширить.

## Технологии

| Технология | Версия | Назначение |
|---|---|---|
| **Rust** | Edition 2024 | Язык реализации. Требуется Rust 1.85+ (MSRV `ed25519-dalek 3.0` — 1.85) |
| **sha2** | 0.11.1 | SHA-256: ID транзакций, хеши блоков, PoW |
| **postcard** | 1.1 (feature `use-std`) | Компактная бинарная сериализация (замена `bincode`) |
| **serde** | 1.0.229 (feature `derive`) | Автоматическая сериализация структур |
| **num-bigint** | 0.5.1 | 256-битные числа для сравнения хешей в PoW |
| **num-traits** | 0.2.19 | Трейты, нужные `num-bigint` |
| **data-encoding** | 2.11.1 | Hex-кодирование хешей для печати |
| **ed25519-dalek** | 3.0.0 (feature `rand_core`) | Ed25519: подписи и проверка |
| **rand** | 0.10.4 | Генерация ключей из OS-энтропии |
| **sled** | 0.34 | Встраиваемая key-value БД для персистентности |

### Почему эти крейты

- **`postcard` вместо `bincode`**: `bincode 1.3.3` помечен как unmaintained (RUSTSEC-2025-0141), `bincode 3.0.0` — «надгробие», не собирается. `postcard` активен, компактен (varint), `no_std`-совместим.
- **`ed25519-dalek 3.0`**: современная реализация Ed25519, совместимая с `rand_core 0.10`, используется в production-проектах (Solana, Near).
- **`sled 0.34`**: встраиваемая БД без внешних зависимостей, с транзакциями и деревьями (`Tree`), идеальна для учебного проекта.
